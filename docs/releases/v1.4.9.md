# Quest APK Renamer 1.4.9

This release makes the connected Quest the source of truth for managed update identities and
introduces a new application icon.

## Headset-managed update identities

- Each managed renamed app stores its own verified update identity under
  `/sdcard/QAPKR/identities/<package>` on the headset where it is installed.
- Identity uploads are staged, SHA-256 verified, and committed atomically so an interrupted
  replacement cannot invalidate the previous usable key.
- The Library can export, restore, replace, or remove a selected app's private `.qarlib` recovery
  identity.
- New keys stay in recoverable desktop cache until a verified installation stores them on every
  target headset used during that session.

## Library and update workflow

- The Library is now a focused live view of applications installed on the connected headset. The
  separate desktop key-vault mode has been removed.
- Older desktop records remain available only for migrating an installed app to its headset-owned
  identity on the next verified update.
- Managed updates refuse a different source game and block missing, corrupt, mismatched, or
  checksum-invalid identities instead of silently generating a replacement key.
- Finished builds reopened after a restart, Dashboard installs, and Bulk installs all resolve the
  same package-specific identity workflow.

## Reliability and verification

- Package rewrites fail closed when decoded references cannot be scanned.
- OBB transfers are verified with SHA-256 before an install is considered successful.
- Queued headset refreshes preserve the useful device result instead of replacing it with stale
  state.
- CI now checks Linux, Windows, and macOS source behavior, validates QML, audits runtime
  dependencies, and verifies pinned workflow tooling.

## Appearance

- The new cross-platform application icon represents an Android package document being edited and
  signed.

Use Quest APK Renamer only with APK/OBB bundles you own or are authorized to modify. Export a
managed app's `.qarlib` recovery identity if you need a backup outside the headset.
