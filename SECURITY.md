# Security policy

## Supported version

Security fixes are currently applied to the latest release only.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving command execution,
path traversal, unsafe output deletion, signing-key exposure, or release
artifact tampering.

Use GitHub's **Security → Report a vulnerability** private reporting feature
when it is enabled for the repository. If private reporting is unavailable,
contact the repository owner privately before sharing technical details.

Include:

- the affected version and platform;
- a minimal reproduction without copyrighted APK/OBB data;
- the expected and observed behavior; and
- any suggested mitigation.

Do not include signing keys, passwords, headset serial numbers, access tokens,
or proprietary game files.
